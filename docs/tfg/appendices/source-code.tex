\chapter{Código fuente}
\label{appendix:source-code}

El código fuente del proyecto se encuentra organizado como un monorepositorio
con las aplicaciones de backend y frontend y los paquetes compartidos.

El repositorio se encuentra en
\url{https://github.com/fervalnav/tfg-fernando}. La rama \texttt{main} contiene
la versión integrada. El acceso requiere los permisos que tenga configurados
el repositorio; no se incluyen credenciales en esta memoria.

El archivo \texttt{README.md} describe la estructura y los comandos generales.
El \Cref{chap:user-manual} explica la instalación y el despliegue, y los
directorios \texttt{infra/hetzner} y \texttt{deploy} conservan los procedimientos
reproducibles de infraestructura, publicación, copias y restauración. La
memoria se mantiene en \texttt{docs/tfg}, con \texttt{main.tex} como punto de
entrada y los capítulos y figuras separados en archivos editables.
