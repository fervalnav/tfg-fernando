\section{Visión general}

La solución se organiza como un monorepositorio gestionado mediante
Turborepo. En él se separan la aplicación web desarrollada con Nuxt 4 y Vue 3,
la API implementada con NestJS y el paquete TypeScript que contiene los tipos
compartidos. La API se comunica con PostgreSQL mediante MikroORM, utiliza
RabbitMQ para la mensajería y emplea almacenamiento compatible con S3 para los
adjuntos.
