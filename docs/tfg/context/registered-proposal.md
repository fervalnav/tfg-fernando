# Propuesta registrada en la Universidad de Sevilla

Este documento recoge la información utilizada para registrar oficialmente el
TFG. Es la fuente autoritativa para el título, la descripción y los objetivos
generales del proyecto.

## Título

**LIA: Integración de IA para análisis automático de licitaciones**

## Descripción

El proceso de análisis y cualificación de licitaciones públicas en España es
una tarea intensiva en conocimiento que requiere la revisión manual de
voluminosa documentación técnica y administrativa —pliegos de condiciones,
anuncios de licitación y memorias explicativas— para determinar si una empresa
cumple los requisitos de solvencia exigidos, si el contrato es económicamente
viable y cómo maximizar la puntuación en los criterios de adjudicación. Este
proceso, cuando se realiza de forma artesanal, consume recursos humanos
significativos y está sujeto a errores de omisión.

LIA es una plataforma web de gestión de oportunidades comerciales centrada en
licitaciones públicas, que integra capacidades de inteligencia artificial
generativa para automatizar las tareas de mayor carga cognitiva dentro del
ciclo de vida de una licitación. El sistema permite a equipos de consultoras y
empresas licitadoras gestionar su cartera de oportunidades a través de
pipelines configurables y flujos de trabajo estructurados, y delegar en la IA
la extracción de información clave, la evaluación preliminar de solvencia y la
generación de documentos de análisis.

## Objetivos

### Objetivo general

- Aligerar el proceso de análisis y toma de requisitos de licitaciones
  públicas.

### Objetivos específicos

- Automatizar la detección de solvencia económica para la presentación a la
  licitación.
- Optimizar el coste y el rendimiento del uso de proveedores de inteligencia
  artificial generativa.
- Facilitar la creación de flujos de trabajo para el análisis de licitaciones.

## Tecnologías registradas

- Monorepositorio con Turborepo.
- Aplicación web con Vue 3.
- API con NestJS.
